# Regex Builder

Build and test regular expressions with live matching, explanations and common-pattern presets. Free tool by [Zion Tech Group](https://ziontechgroup.com/).

🌐 **Live:** https://ziontechgroup.com/regex-builder/

## Features
- Live match highlighting with capture groups
- Plain-English explanation of your pattern
- Preset library: emails, URLs, IPs, dates, log formats
- Multi-language flavor notes (JS, Python, PCRE)
